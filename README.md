# Практическая работа: RISC-V / RARS

Студент: **Рожков Кирилл Юрьевич**. Группа: **118**.
Номер в списке: **15**. Параметры: **n = h = 15, y = 118**.
Массив содержит **31** элемент и занимает **124** байта.

## Настройка

В PowerShell, открытом в папке проекта:

```powershell
.\Configure.ps1 -StudentNumber 15 -GroupNumber 118
.\Start-RARS.ps1
```

StudentNumber — номер в списке группы, GroupNumber — целое число,
которое преподаватель использует как номер группы y.
Configure.ps1 одновременно устанавливает n/h, y, длину массива 16+n
и объём памяти 4*(16+n) байт в params.inc.

Локальный комплект содержит RARS 1.6 и переносимую Java 21 в tools/.
Устанавливать Java в систему не требуется.
Эта папка исключена из git. При переносе проекта на другой компьютер
скачайте RARS и установите Java 8 или новее.

Источники: [RARS](https://github.com/TheThirdOne/rars),
[RARS 1.6](https://github.com/TheThirdOne/rars/releases/tag/v1.6),
[Java Eclipse Temurin](https://adoptium.net/).

## Запуск и решения

Откройте в RARS **один** файл task_a.asm, task_b.asm или task_c.asm.
Соберите его через Run → Assemble (F3), затем запустите Run → Go (F5).
Вводите каждое целое число с новой строки в Run I/O.
Используется стандартный режим RV32; сборку всех открытых файлов вместе
следует отключить, поскольку каждая задача имеет свою метку main.

- **а, task_a.asm:** читает x, сравнивает с n, печатает 1 или 0.
- **б, task_b.asm:** определяет нижнюю и верхнюю границы, печатает
  нижнюю границу и увеличивает текущее значение на h до конца диапазона.
  Верхняя граница включается, если попадает в последовательность с шагом h.
  Проверка оставшегося расстояния предотвращает выход за границу
  и переполнение при следующем сложении.
- **в, task_c.asm:** выделяет массив из 16+n 32-битных целых чисел,
  читает и сохраняет их по одному. После сохранения нуля либо заполнения
  массива завершает чтение. Ноль входит в число сохранённых элементов.
  Метка count хранит число прочитанных элементов. Вывод не требуется;
  результат виден в Data Segment по меткам array и count.

Системные вызовы: a7=5 — ввод целого, 1 — вывод целого,
11 — вывод символа, 10 — завершение.
[Документация](https://github.com/TheThirdOne/rars/wiki/Environment-Calls).

## Примеры для параметров студента

| Задача | Ввод (каждое число с новой строки) | Результат |
|---|---|---|
| а | 15 | 1 |
| а | 14 | 0 |
| б | 70 | 70, 85, 100, 115 |
| б | 163 | 118, 133, 148, 163 |
| б | 118 | 118 |
| в | 7, -3, 0, 99 | array: 7, -3, 0; count=3; 99 не читается |
| в | 1…31, 99 | array: 1…31; count=31; 99 не читается |
